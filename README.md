##  Условие задачи (Вариант 14,номер по списку подгруппы)
Три важнейших параметра станка (\(A\), \(B\), \(C\)) должны быть идеально отлажены. Система калибровки выдает сообщение об успехе, если каждое из значений параметра кратно трем. Запишите условие успешной калибровки.

## 1. Алгоритм и блок-схема
##  Алгоритм 
1. **Начало**.
2. **Объявление переменных**: целочисленные `A`, `B`, `C` и `result`.
3. **Вывод на экран** поясняющего текста о правилах калибровки.
4. **Ввод исходных данных**: считать три параметра `A`, `B`, `C`.
5. **Вычисление условия**: 
   `result = (A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)`.
   *Если все три числа кратны 3, `result` принимает значение 1 (Истина), иначе 0 (Ложь).*
6. **Вывод результата**:
   * При `result` = 1 вывести «Калибровка успешна».
   * При `result` = 0 вывести «Калибровка не удалась».
7. **Конец**.

#include <locale.h>

    printf("Введите три параметра через пробел: \n");
    scanf("%d %d %d", &A, &B, &C);
    result = ((A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0));
    result&& printf("Калибровка успешна\n");
    !result && printf("Калибровка не удалась\n");
    return 0;
}
